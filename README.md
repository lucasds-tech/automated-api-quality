# API Test Automation Suite

Projeto desenvolvido para automação de testes de uma API REST, com o objetivo de validar funcionalidades, comportamentos e integrações através de testes automatizados.

## 🚀 Objetivo

Criar uma suíte de testes automatizados capaz de executar cenários de validação da API, garantindo maior confiabilidade nas entregas e reduzindo a necessidade de testes manuais repetitivos.

## 🛠️ Tecnologias utilizadas

* Java
* JUnit 5
* Rest Assured
* Maven
* AssertJ
* Jackson
* Allure Report

## 🚧 Status do projeto

Em desenvolvimento.

Novas funcionalidades, cenários de testes e melhorias na estrutura de automação serão adicionados continuamente conforme a evolução do projeto.
